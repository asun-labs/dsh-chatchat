# IP as Logo avatar catalog

These 16 illustrations were downloaded from https://ipaslogo.com/ (redirects to https://visualskills.dev/ip-as-logo) on 2026-11-13 using the site's preview/original-image download controls. The robot search showed 79 results. Each catalog entry records its original title, exact original PNG URL, original SHA-256 and bundled-thumbnail SHA-256.

The library displays the permission statement "可免费下载并免费商用。" (free download and free commercial use). This statement applies to the website's logo library; the MIT license on https://github.com/s1dashu/ip-as-logo-skill covers the companion skill repository and is not represented here as a separate image license.

For offline use, each original square PNG was resized as a complete image to 160 × 160 pixels with high-quality bicubic interpolation. No artwork, colors, background or facial features were redrawn or replaced. These are third-party IP as Logo works, not illustrations created by DSH ChatChat. The normal Bot image animations move the whole image; these PNGs do not contain separate blinking-eye or mouth-animation frames.

The old hand-drawn and third-party robot collections are removed from the selectable catalog. Existing images stored on individual Bots remain untouched. The DS Bot code's original licenses and notices remain in the plugin's third-party directory.
