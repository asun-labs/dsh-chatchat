# DSH ChatChat v0.1.11

- 独立 DSH 安装默认进入完整 ChatChat 界面，使用插件自身的 Bot 侧栏与原生会话内容；不再挤在原生侧栏的嵌入面板中。
- 左上角返回按钮恢复 DSH 原生界面及原侧栏宽度；原生侧栏的 ChatChat 入口可再次进入，每次启动默认进入 ChatChat。
- 打开原生模型设置前退出独立 ChatChat 界面，使模型设置可见。保留 0.1.10 的模型配置与选择引导。
- 默认团队工作区名称跟随 DSH / Seal 品牌，迁移已有默认标题并保留其他自定义标题；选择已有工作区时继续沿用原名称。
- Seal 等显式宿主继续管理自己的导航、返回办公入口与设置接入，不启用独立 DSH 界面接管。
- 保留既有 Bot、群聊、会话、数据目录与第三方许可证。

验证：Windows 独立界面进入/退出、侧栏宽度恢复、导航清理、品牌迁移及宿主边界回归；发布流程执行 Ubuntu 完整回归、集成测试、预编译打包与 SHA-256 校验，通过后发布。macOS、Android 未实测。本版本只发布 ChatChat 插件，不包含 Seal 桌面安装器，也不自动修改 Seal 的固定依赖版本。
