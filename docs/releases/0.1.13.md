# DSH ChatChat v0.1.13

- 修复快速切换 Bot 后返回原会话时复用已释放的 SessionReference，导致整个 Bot 页面空白的问题。每个会话子树独立持有引用，保留聊天历史和原生会话实现。
- 修复选中其他 Bot 后又自动跳回主 Bot 的问题。嵌入页以实际选中会话为准，会话目录短暂缺项不再触发主 Bot 兜底跳转。
- 增加快速返回、延迟打开、同一会话从目录移除后恢复、目录缺项时保留显式选择的回归。

验证：Windows 定向回归通过；发布工作流须通过 Ubuntu 继承回归、集成测试、预编译打包和 SHA-256 校验后发布。macOS、Android 未实测。本版本发布独立预编译插件，不包含 Seal 桌面安装器。
