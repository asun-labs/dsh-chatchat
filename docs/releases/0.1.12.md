# DSH ChatChat v0.1.12

- 修复已设置跟随 Seal 模型时仍出现首次选模型引导的问题。显式宿主接入下，Bot 未单独指定模型且宿主默认模型可用时，不再要求重复选择。
- 引导只读取模型状态，不替用户固定某个模型，也不修改提供商、凭据或既有 Bot 配置；继续沿用原生会话的模型行为。
- 缺少可用默认模型或 API Key、显式模型失效时继续显示配置或修复提示；独立 DSH 的首次选模型流程保持不变。

验证：Windows 已通过相关 React 回归及实际 Seal 界面验证，确认设置仍为跟随 Seal、重复提示消失；发布流程通过 Ubuntu 完整回归、集成测试、预编译打包及 SHA-256 校验后发布。macOS、Android 未实测。本版本只发布 ChatChat 插件，不包含 Seal 桌面安装器，也不自动修改 Seal 的固定依赖版本。
