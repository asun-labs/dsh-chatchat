# DSH ChatChat v0.1.14

- 修复嵌入界面中 Bot 回复正文被原生紧凑 Markdown 的三级文字色覆盖的问题；正文恢复主文字色，时间等辅助信息保留层次。
- 私聊气泡和平铺布局均显示回复 Bot 的头像、名称与时间，历史回放和流式回复一致。
- 修复部分历史分页中，较早的思考或正文步骤导致当前回复缺少发言者标识的问题。

验证：Windows 定向回归、独立预编译包构建及内容检查；发布工作流须通过 Ubuntu 继承回归、集成测试、打包和 SHA-256 校验后发布。macOS、Android 未实测。本版本仅发布独立插件，不包含 Seal 桌面安装器。
