# DSH ChatChat v0.1.9

- 从专家模板创建 Bot 使用响应式卡片布局：宽屏每行三张卡片，较窄窗口自动调整为两列或一列；保留系统/个人分类、搜索与独立配置副本。
- 修复新建面板覆盖宿主侧栏按钮：新建、模板、交换与语音面板从实际会话区域边缘开始，随侧栏折叠与尺寸变化更新。
- 原生 DSH 的 Bot 搜索、新建工具显示在原生新会话按钮上方，保留原按钮与折叠能力；离开 Bot 页面时清理工具栏，重新进入不重复挂载。
- 原生 DSH 不再显示无效的返回办公按钮；Seal 等宿主明确提供的返回操作继续保留。
- 保留已有 Bot、群聊、会话历史、头像与数据目录，不更改认证或用户配置。

验证：发布流程执行 Ubuntu 完整回归、集成测试与预编译打包校验，通过后生成不可变版本包及 SHA-256。Windows 已完成相关 React/SlotCore 回归，以及 Seal 中三列卡片和新建面板的实际界面验证；macOS、Android 未实测。本版本只发布 ChatChat 插件，不包含 Seal 桌面安装器，也不自动修改 Seal 的固定依赖版本。
