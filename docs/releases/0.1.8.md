# DSH ChatChat v0.1.8

- Bot 默认名称和图标跟随宿主。独立 DSH 安装显示 DSH Bot / DSH Agent 与官方鲸鱼标识；Seal 适配显示 Seal Bot / Seal Agent 与原海豹标识。
- 菜单、侧栏、搜索、设置与默认图标使用同一品牌配置。自定义 Agent 名称得到保留。
- 默认主 Bot 的品牌升级保留会话历史；用户修改名称或头像后，对应字段不再由品牌升级覆盖。显式选择与默认名称相同的自定义名称也会保留。
- 保留原数据目录、存储键、协议与原生会话；不按可执行文件路径猜测宿主。
- 官方 DSH 图标来自固定提交的桌面资源，随包保留 MIT 许可证、来源及原始文件摘要。

验证：Windows 隔离 Host/Client 双品牌与迁移回归，Seal 适配回归；线上 Ubuntu 完整回归、集成测试和预编译打包校验通过后发布。此版本不包含 Seal 桌面安装器。
