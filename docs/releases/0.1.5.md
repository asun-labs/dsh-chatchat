# DSH ChatChat v0.1.5

- Bot 详情改为角色、人设、动态和资源视图；模型、权限、工作文件夹等统一放入设置，保留浏览器入口。
- 左侧使用常驻搜索框；原主 Bot 动画移至右侧详情。新建分组位于加号菜单，默认中文名称。
- 普通新建 Bot 可填写长期职责说明，创建后可独立修改。
- 宿主提供专家模板服务时，新增“新建 Bot－选择从模板中创建”，支持系统/个人目录。选定模板后只需填写名称，复制默认配置与能力；后续不跟随原专家更新。
- 模板能力在首次消息、重启恢复、会话分段和群聊中装配；修复恢复初始化期间重复进入维护状态的问题。

模板目录及能力由宿主提供，独立 DSH 安装不自动附带 Seal 的专家服务。

本版本为 DSH 0.2.2-rc.3 适配的预编译插件包，安装不执行源码构建。保留已有 Bot、群聊、记忆与会话数据。

验证：Windows 本地回归与界面实测；线上 Ubuntu 构建、继承回归、集成测试和真实 tarball 校验均须通过后才发布。未实测 macOS 桌面。

下载 `.tgz` 及同名 `.sha256`，核对摘要后通过 DSH 插件管理器安装。`.tgz.json` 提供包版本、SHA-256、SHA-512 和文件计数。此发布不包含 Seal 桌面安装器，也不向 npm registry 发布。
