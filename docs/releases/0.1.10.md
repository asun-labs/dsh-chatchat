# DSH ChatChat v0.1.10

- 恢复 Bot 输入区的模型配置引导：尚无模型时提示配置，有可用模型但尚未选择时提示选择，显式选择后收起引导。
- 原生 DSH 的配置入口直接打开原生设置中的模型分类，避免进入不包含模型管理的精简 Bot 设置页。
- 原生设置入口不可用时给出明确错误；动态读取当前设置服务，支持设置插件后加载。
- 保留 Seal 等宿主显式提供的设置接入，不改变本地 Agent 的模型行为、认证与已有数据。
- 包含 0.1.9 的三列模板卡片、新建面板边界和原生顶部工具栏修复。

验证：Windows React 状态切换及原生设置接入回归；发布流程执行 Ubuntu 完整回归、集成测试、预编译打包与 SHA-256 校验，通过后发布。macOS、Android 未实测。本版本仅发布 ChatChat 插件，不包含 Seal 桌面安装器，也不自动调整 Seal 的固定依赖版本。
